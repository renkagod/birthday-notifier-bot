Telegram-бот для автоматических напоминаний о днях рождения с современным интерфейсом и гибкими настройками.

## Особенности

- **Умное текстовое добавление**: добавление в одно сообщение на естественном языке (например, `Иван 15.08.1990` или `Маша 3 августа`).
- **Интерактивный UI**: управление списком, изменение деталей, выбор даты и удаление осуществляются полностью через inline-кнопки с пагинацией (страницы по 8 контактов).
- **Поддержка дат без года**: возможность пропускать год рождения (в списках выводится формат `ДД.ММ` без указания возраста).
- **Импорт контактов**: добавление из телефонной книги Telegram в один клик.
- **Telegram-теги**: автоматическая привязка `@username` для упоминаний в уведомлениях.
- **Гибкие уведомления**:
  - Плановые: за месяц, неделю, 3 дня, накануне (завтра) или сегодня в выбранное время.
  - Оперативные: за 30 и 5 минут до наступления.
  - Полночные: поздравление ровно в 00:00 (флаг `-1.0` в настройках).
- **Сортировка списка**: по имени (алфавиту) или по дате приближения праздника.
- **Бэкапы**: экспорт всего списка в JSON и импорт обратно.
- **Docker**: готовый образ, Docker Compose, встроенные лимиты ресурсов и настройка часового пояса.

## Быстрый старт (Docker)

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/renkagod/birthday-notifier-bot.git
   cd birthday-notifier-bot
   ```

2. Настройте конфигурацию:

   ```bash
   cp .env.example .env
   # Укажите BOT_TOKEN в .env
   ```

3. Запустите:

   ```bash
   docker compose up -d --build
   ```

## Использование

После запуска отправьте боту `/start`.

- **📅 Мой список** — интерактивное меню просмотра контактов с постраничной навигацией, быстрым переименованием, изменением даты или удалением.
- **➕ Добавить** — добавление контакта вручную, отправка контакта из Telegram или пошаговый интерактивный календарь.
- **🔥 Ближайшие** — именинники ближайших 30 дней.
- **⚙️ Настройки** — настройка времени ежедневных напоминаний и активных интервалов (с поддержкой быстрых пресетов).
- **💾 Бэкап** — экспорт списка в JSON файл или его восстановление из файла.

## Разработка и локальный запуск

Для разработки вам понадобится Python 3.10+:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env        # укажите ваш BOT_TOKEN

# Запуск тестов и линтера
ruff check bot tests
pytest -v

# Запуск бота
python -m bot.main
```

## Конфигурация

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от [@BotFather](https://t.me/BotFather) |

Для локальной разработки можно задать переменную `BIRTHDAY_BOT_DB_PATH` для изменения пути к SQLite базе данных (по умолчанию `data/birthdays.db`).
